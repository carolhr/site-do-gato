Bem-vindo ao repositório do **Site do Gato**, uma página web interativa, colorida e divertida feita para quem ama felinos! 🐾

---

## 🎨 O que este site faz?
Atualmente, o projeto conta com as seguintes interatividades:
* **Botão de Ação Principal:** Um botão dinâmico que exibe um gatinho fofo e uma mensagem de sucesso na tela.
* **🐾 Rastro de Patinhas:** Pequenas patinhas rosa neon que seguem o movimento do cursor do mouse por toda a tela escura.
* **💡 Gerador de Curiosidades:** Um botão dedicado que sorteia fatos interessantes e informativos sobre a biologia e comportamento dos gatos.
* **🎵 Efeitos Sonoros & Ícones (Em Breve):** Estrutura preparada para tocar miados reais e exibir um favicon personalizado.

---

## 🛠️ Tecnologias Utilizadas
Para manter o projeto leve, organizado e moderno, o código foi totalmente componentizado utilizando:
* **HTML5:** Estruturação semântica e limpa dos elementos da página.
* **CSS3:** Estilização escura baseada na paleta *Dracula*, incluindo animações fluidas (`@keyframes`) e efeitos ao passar o mouse (`:hover`).
* **JavaScript Puro (Vanilla JS):** Manipulação de eventos do DOM para capturar o movimento do mouse e gerenciar o sorteio de curiosidades.
